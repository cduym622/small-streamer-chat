# Small Streamer Chat

A free desktop tool that gives new streamers an AI-generated chat to talk to while they have few or no viewers. It listens to the streamer and shows a simulated chat, without ever posting to a streaming platform.

## Language

**Streamer**:
The person using the tool and broadcasting live.
_Avoid_: User, host, creator

**Practice Chat**:
The simulated chat feed the tool produces. It exists only on the streamer's machine and is never posted to a platform.
_Avoid_: Fake chat, bot chat, AI chat

**AI Chatter**:
A named persona that writes messages in the Practice Chat, always marked as AI.
_Avoid_: Bot, fake viewer, viewer

**Persona**:
The personality and style definition an AI Chatter speaks from. The tool ships with built-in ones, and the streamer can edit or add more.
_Avoid_: Character, profile

**Overlay**:
The Practice Chat rendered for capture by streaming software (e.g. an OBS browser source), optionally styled like a platform's native chat.
_Avoid_: Widget, embed

**Real Chat**:
The actual chat on the streamer's platform channel, which the tool may read but never writes to.
_Avoid_: Live chat, platform chat

**Real Chatter**:
A human who posts in the Real Chat.
_Avoid_: Viewer, user

**Back-off**:
The Practice Chat quieting down because Real Chatters are active.
_Avoid_: Pause, mute
